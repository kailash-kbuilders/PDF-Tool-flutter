# PDF Toolkit

Offline PDF editor and utility app (Flutter, Material 3). All processing is on-device.

## Termux se push

    git init
    git add .
    git commit -m "pdf toolkit"
    git branch -M main
    git remote add origin https://github.com/USERNAME/REPO.git
    git push -u origin main --force
